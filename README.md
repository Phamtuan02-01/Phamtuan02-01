# 💫 About Me:
🎓 Sinh viên năm 3 ngành Công nghệ Thông tin tại Đại học Công nghiệp TP.HCM, có nền tảng vững về phát triển giao diện web.<br><br>💻 Thành thạo HTML, CSS, JavaScript (ES6+), ReactJS, Bootstrap, Tailwind CSS và có kinh nghiệm sử dụng ASP.NET MVC 4.<br><br>🧩 Tham gia nhiều dự án cá nhân và nhóm như MovieHub, Tour Management, E-Commerce và Supermarket Management với vai trò lập trình giao diện.<br><br>⚙️ Sử dụng thành thạo Git, GitHub, Visual Studio Code, Figma và các công cụ quản lý như Notion, Trello.<br><br>🚀 Luôn chủ động học hỏi, từng hoàn thành khóa học Front-End từ F8 và đang tiếp tục rèn luyện kỹ năng qua các dự án thực tế.
